STEP 1 – Install Python
• Go to https://python.org/downloads
• Download latest Python 3.x installer
• Run the installer
• IMPORTANT: Check the option “Add Python to PATH”
• Click Install

Verify installation (in Command Prompt / Terminal):
python --version
pip --version


STEP 2 – Install Node.js
• Go to https://nodejs.org
• Download the LTS (Long Term Support) version
• Run the installer and complete installation

Verify installation (in Command Prompt / Terminal):
node --version
npm --version


STEP 3 – Install Yarn (Optional)
Where: Command Prompt / Terminal

Command:
npm install --global yarn

Verify installation:
yarn --version


STEP 4 – Install VS Code
• Go to https://code.visualstudio.com
• Download VS Code installer
• Run installer
• Select “Add to PATH” option
• Finish installation


STEP 5 – Open VS Code from Terminal
Where: Command Prompt / Terminal

Command:
code .


STEP 6 – Install Python Linter
Where: VS Code Terminal or Command Prompt

Command:
pip install pylint
# OR
pip install flake8


STEP 7 – Install Python Formatter
Where: VS Code Terminal or Command Prompt

Command:
pip install black


STEP 8 – Install ESLint for JavaScript/React
Where: Inside your project folder terminal

Command:
npm install --save-dev eslint eslint-plugin-react


STEP 9 – Install Prettier Formatter
Where: Inside project folder terminal

Command:
npm install --save-dev prettier


STEP 10 – Run Frontend Files using Live Server
Where: VS Code

• Install “Live Server” extension
• Open an HTML file
• Right click the file
• Select “Open with Live Server”
• Browser opens automatically and reloads when code changes
